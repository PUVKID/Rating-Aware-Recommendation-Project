## 🧩 평점 정보와 가중 결합

ML-100K, ML-Latest-Small, ML-1M, CiaoDVD를 사용한 비교를 설명합니다. 평점 임계값은 추가 그래프에 남길 상호작용을 고르는 기준입니다. 기존 그래프를 함께 사용하는 이유는 낮은 평점의 상호작용까지 모두 버리면서 생길 수 있는 정보 손실을 줄이기 위해서입니다. 기본 결합 비율은 5:5이며 Ratings5의 ML-Latest-Small은 7:3, ML-1M은 8:2의 예외를 둡니다. 따라서 두 설정의 차이를 평점 임계값 하나의 효과로 해석하지 않습니다.

원고는 alpha1 0.3, alpha2 0.7, 필터 차수 8, 특이성분 수 256, 군집 수 5, random_state 2024를 기술합니다. 환경표와 패키지 버전은 당시 원고의 기록이며 현재 환경에서 실행 확인한 설정이 아닙니다.

<a name="원고가-보고한-결과와-한계"></a>

### 🔎 원고가 보고한 결과와 한계

원고의 Ratings2는 24개 데이터셋·지표 조합 중 23개에서 향상을 보고하며, ML-1M MRR@10은 0.5603에서 0.5601로 감소합니다. Ratings5는 24개 모두 향상했다고 보고합니다. CiaoDVD MRR@5의 상대 향상 16.54%는 절대값 0.0133→0.0155의 차이와 함께 해석해야 합니다.

CiaoDVD에서는 K=5의 세 지표 모두 Ratings5가 Ratings2보다 높지만, K=10에서는 Ratings2가 더 높습니다. 따라서 임계값 5가 언제나 더 좋은 설정이라고 해석하지 않습니다.

| 데이터셋 | 사용자 | 아이템 | 상호작용 수 | 평점 범위 |
| :--- | ---: | ---: | ---: | :--- |
| ML-100K | 943 | 1,682 | 100K | 1~5 |
| ML-Latest-Small | 610 | 9,724 | 100K | 0.5~5.0 |
| ML-1M | 6,040 | 3,706 | 1M | 1~5 |
| CiaoDVD | 17,615 | 16,121 | 72K | 1~5 |

위 규모는 원고 5쪽 표의 표기입니다. 원고는 ML-100K·ML-1M의 학습·시험 자료를 새로 분할했다고 설명하지만, 공개 실행 코드나 분할 목록은 제공하지 않습니다. F1은 추천 목록의 정밀도·재현율을 함께, MRR은 정답의 순위를, NDCG는 순위에 따른 관련도를 비교하는 지표입니다. 결과는 모두 K=5·10으로 나누어 읽어 주세요.

실행시간·메모리를 측정하지 않아 계산 효율 향상은 확인되지 않았습니다. 추가 그래프 처리 비용, 가중치 차이와 통계적 유의성의 한계를 구분합니다.
