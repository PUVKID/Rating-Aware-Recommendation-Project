# 📄 내 논문 PDF와 공식 링크 교체 위치

현재 링크에서 논문 공개본을 읽을 수 있습니다. 나중에 공개된 공식 논문 URL을 확인하면 아래 `공식 공개 URL` 열과 첫 화면의 `내 논문 PDF` 항목을 함께 교체합니다. 공식 링크가 공개되면 현재 PDF 링크와 함께 갱신합니다.

| 원고 단계 | 지금 바로 읽는 PDF | 편집 원본 | 공식 공개 URL(교체 위치) |
|---|---|---|---|
| 최종 원문 | [PDF 원문](../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EC%9B%90%EB%AC%B8_%EB%85%BC%EB%AC%B8.pdf) | [원본](../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EC%9B%90%EB%AC%B8_%EB%85%BC%EB%AC%B8.hwp.md) | 미등록 — 공식 URL 확인 후 이 칸 교체 |

저자 성명·학교·이메일·전화·저자소개·사진을 보존하고 학과 정보를 제외한 PDF를 제공합니다. 현재 최종 링크는 지정한 사진 포함 PDF로 통일했습니다. 이전 공개 사본은 로컬에 보존합니다. 인증정보·식별 가능한 환자 의료 원본·별도로 보관하는 외부 비공개 자료는 포함하지 않습니다.


> 공개 PDF에서는 지정된 개인정보와 학과·학부 정보를 제외했습니다. 저자·공동저자의 성명, 학교, 이메일, ORCID와 사진은 보존합니다. 편집 원문 링크는 비공개 보관 안내로 연결됩니다.

현재 최종 원고는 [사진을 포함한 최종 PDF](../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EC%9B%90%EB%AC%B8_%EB%85%BC%EB%AC%B8.pdf)입니다. 이전 초안은 해당 차수의 자료로 구분합니다.
