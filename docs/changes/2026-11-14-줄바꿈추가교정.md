# 좁은 화면의 줄바꿈 추가 교정

## 2026-11-14

실제 GitHub 휴대폰 화면에서 확인한 좁은 셀의 한 글자 줄바꿈을 바로잡기 위해 링크 목차를 한 열의 전체 폭 표로 모으고 설명·입력 조건 표는 전체 폭 문단으로 옮겼습니다.

실제 숫자·단위만 비교하는 수치표는 유지했습니다.

다섯 읽기 수준과 차수별 자료·상세·직전 비교를 같은 행에서 연결하고, 원문 셀·관측값·조건·코드·주소·앵커를 보존합니다.

원고·이미지 등 문서 외 파일과 기존 변경 기록은 편집하지 않았습니다.

[전체 문서 비교](2026-11-14-줄바꿈추가교정-전체비교.md)

공식 게재 링크로 읽는 기존 논문 연결은 유지합니다. 현재 기준선에 없는 PDF를 이번 차수의 새 삭제로 기록하지 않습니다.
