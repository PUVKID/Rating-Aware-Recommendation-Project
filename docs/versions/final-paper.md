# 📄 최종 원고

상호작용 그래프와 평점 정보를 결합하여 추천 순위를 평가하는 원고입니다.

[최종 원고 읽기](../../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EB%85%BC%EB%AC%B8.pdf) · [프로젝트 소개](../../README.md) · [보관 기록](../VERSIONS.md)

## 🔎 읽을 때 주의할 점

공개 실행 코드나 데이터 분할 목록은 제공하지 않습니다. 학회지 양식만으로 게재 완료를 뜻하지 않습니다.

이 저장소에는 최종 원고 한 개가 있습니다. 실행 코드와 이전 원고 차수는 공개 자료에 포함되어 있지 않습니다.


## 🧩 구체적으로 살펴볼 내용

- 두 그래프를 결합하는 설계와 네 데이터셋의 평점·상호작용 구성을 설명합니다.
- K별 Recall·NDCG·MRR 결과를 구분합니다. 모든 지표가 일괄 개선된 것으로 요약하지 않고 ML-1M의 MRR@10 감소도 함께 읽습니다.

## 🔄 앞선 자료와의 관계

이 저장소는 최종 원고 한 편을 공개합니다. 이전 원고 차수·실행 코드·재현 데이터가 없으므로 가상의 1차·2차 변경 비교를 만들지 않습니다.
