# 📄 최종 원고

상호작용 그래프와 평점 정보를 결합하여 추천 순위를 평가하는 원고입니다.

[최종 원고 읽기](../../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EB%85%BC%EB%AC%B8.pdf) · [프로젝트 소개](../../README.md) · [연구 자료](../VERSIONS.md)

## 🔎 연구 범위

추천 그래프의 구성과 데이터셋별 비교 결과를 원고에 정리했습니다.

상호작용 그래프와 평점 기반 그래프의 필터 점수를 결합하는 추천 구조를 최종 원고에 정리했습니다.


## 🧩 주요 내용

- 두 그래프를 결합하는 설계와 네 데이터셋의 평점·상호작용 구성을 설명합니다.
- K별 F1·NDCG·MRR을 비교하며, ML-1M에서는 MRR@10이 감소한 결과도 함께 보고합니다.

## 🔄 자료 구성

해당 최종 원고를 포함한 모든 이전 단계와 실제 파일은 [전체 차수 색인](../REVISION_INDEX.md)에서 함께 확인합니다.
