<a id="guide-intro"></a>

## 프로젝트 소개

공개 원고의 수식·설정·결과표를 대조하는 연구 자료입니다. 실행 코드와 분할 목록은 제공하지 않습니다. 동일 수치의 재실행에 필요한 입력이 있는지 먼저 확인하고 논문 보고값을 새 실측으로 적지 않습니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

Ratings2는2이상, Ratings5는5이상의 관측 상호작용을 추가 그래프에 남깁니다. 이를 추천 결과의 점수 임계값으로 읽지 않습니다. 후보 선택 기준과 추천 평가 기준을 구분하세요.

<a id="guide-flow"></a>

## 입력·처리·출력

ML-100K·ML-Latest-Small·ML-1M·CiaoDVD의 자료 조건을 확인합니다. Ratings5의 ML-Latest-Small은7:3, ML-1M은8:2이며 기본은5:5입니다. 임계값 차이와 가중치 차이를 함께 기록해야 합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

원고의 수식→자료 통계→분할 설명→결합 비율→F1/MRR/NDCG표 순서로 대조합니다. 코드나 분할 목록이 없으므로 그대로 재실행했다고 할 수 없습니다. 기존 문서 차수의 원고 변화는 전체 비교에서 확인합니다.

<a id="guide-results"></a>

## 관측 결과와 해석

저장 보고값을 그대로 확인하고 절대 차이와 상대 변화율을 나누세요. CiaoDVD의0.0022 증가와16.54%는 같은 차이의 다른 표현입니다. Ratings2와5 중 어느 쪽이 좋은지도 K와 지표에 따라 달라집니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

파일 역할은 공식 게재 링크와 기존 투고 원고, 차수 상세·전체 비교로 나눕니다. 논문의 알고리즘 설명을 호출 가능한 함수·명령이 제공된 상태로 설명하지 않습니다.

## LEVEL 3 · 조건과 결과를 자세히 읽기

아래 조건은 원고·공개 노트북에 있는 값입니다. 차수별 상세는 각 단계의 기록이며, 최신 원고의 설정을 이전 차수에서 새로 얻은 결과로 소급하지 않습니다.

### LEVEL 3 · 두 그래프의 역할

**실제 조건:** 전체 사용자·아이템 상호작용 그래프 + 평점 임계값 그래프. Ratings2는 2 이상, Ratings5는 5 이상. 군집·그래프 필터링 뒤 두 경로 점수를 결합합니다.

원고의 두 인접행렬 구성부터 확인합니다. 각 데이터셋 평점 범위에서 2·5 임계값을 적용하고 사용자 군집·필터·점수 결합 조건을 함께 기록합니다. 단일 경로 결과를 두 경로 결합 결과와 같은 설정으로 비교하지 않습니다.

### LEVEL 3 · 네 데이터셋의 규모

**실제 조건:** 원고 표기: ML-100K 943명/1,682아이템/100K/1~5점; ML-Latest-Small 610명/9,724/100K/0.5~5.0점; ML-1M 6,040명/3,706/1M/1~5점; CiaoDVD 17,615명/16,121/72K/1~5점.

입력 준비 시 이름뿐 아니라 세 규모와 평점 범위를 원고 표와 대조합니다. ML-100K·ML-1M은 새로 학습/시험 분할했다고 설명하지만 공개 분할 목록이 없으므로 동일 분할을 확보하기 전에는 논문 재현 완료로 기록하지 않습니다.

### LEVEL 3 · 결합 비율과 필터 설정

**실제 조건:** HiGSP:평점 경로 기본 5:5. Ratings5의 ML-Latest-Small 7:3, ML-1M 8:2. alpha1=0.3·alpha2=0.7·차수8·특이성분256·군집5·random_state2024.

비교표마다 임계값과 5:5/7:3/8:2를 함께 적고, alpha1 0.3·alpha2 0.7·차수8·성분256·군집5·seed2024를 빠짐없이 대조합니다. 코드와 분할 목록이 없는 상태에서 이 설정표만으로 실행을 재현했다고 보고하지 않습니다.

### LEVEL 3 · 추천 지표와 목록 길이

**실제 조건:** K=5·10, F1·MRR·NDCG. 네 데이터셋 × 두 K × 세 지표 = 24조합.

결과표에서 데이터셋·K·지표 이름을 먼저 고정한 뒤 HiGSP·Ratings2·Ratings5 열을 비교합니다. F1과 MRR을 혼합하거나 K=5 결과를 K=10 기준값과 비교하지 않습니다. 미제공 분할·평가 코드는 재현 입력의 남은 항목으로 기록합니다.

### LEVEL 3 · 개선 수와 감소한 조건

**실제 조건:** Ratings2 23/24 향상, ML-1M MRR@10 0.5603→0.5601 감소. Ratings5 24/24 향상. 모두 원고 보고 결과입니다.

24칸의 방향을 다시 확인하고 ML-1M MRR@10의 두 원값을 함께 기록합니다. 원고의 23/24·24/24 보고를 새 실행 검증으로 바꾸지 않습니다. 동일 분할의 반복 결과나 유의성 검정이 필요한지는 별도 평가 계획으로 둡니다.

### LEVEL 3 · 절대 점수·상대 향상과 K별 역전

**실제 조건:** CiaoDVD MRR@5 0.0133→0.0155, 절대 차이0.0022·원고 보고 상대 향상률16.54%. K5의 세 지표는 Ratings5가 더 높고, K10은 Ratings2가 더 높습니다.

0.0133·0.0155 두 값을 보존하고 절대 차이와 상대율의 단위를 나누어 표기합니다. 원고의 16.54%는 원문 표기이며 새 요약 표시의 반올림과 구분합니다. CiaoDVD 결과를 K5·K10 두 표에서 각각 확인합니다.

### LEVEL 3 · 자료 범위와 논문 읽기

**실제 조건:** 한국사물인터넷학회, 사물인터넷융복합논문지12(5),25–33쪽,2026.10,김희찬·곽윤석·김남기. 공식 KCI 링크. 기존 HWP는 투고본; 공개 실행 코드·분할 목록·실제 사용자 로그는 제공하지 않습니다.

공식 KCI에서 제목·세 저자·권호·25–33쪽을 확인하고 방법·환경표·결과·한계 순으로 읽습니다. 과거10쪽 투고본과 현재9쪽 게재본을 구분합니다. 코드·환경 파일·분할 목록이 없으므로 실행 명령을 만들어 재현한 것으로 기록하지 않습니다.

### LEVEL 3 · 평점 정보와 가중 결합


ML-100K, ML-Latest-Small, ML-1M, CiaoDVD를 사용한 비교를 설명합니다. 평점 임계값은 추가 그래프에 남길 상호작용을 고르는 기준입니다. 기존 그래프를 함께 사용하는 이유는 낮은 평점의 상호작용까지 모두 버리면서 생길 수 있는 정보 손실을 줄이기 위해서입니다.

기본 결합 비율은 5:5이며 Ratings5의 ML-Latest-Small은 7:3, ML-1M은 8:2의 예외를 둡니다. 두 설정의 비교에는 평점 임계값과 그래프 결합 비율의 영향이 함께 반영됩니다.

실험 설정은 alpha1 0.3, alpha2 0.7, 필터 차수 8, 특이성분 수 256, 군집 수 5, random_state 2024입니다. 당시의 환경과 패키지 버전은 원고의 환경표에 정리했습니다.

### LEVEL 3 · 자료 구성과 결과 해석


현재 게재본은 공식 KCI 페이지로 안내하고 기존 편집 원본은 투고 원고로 보존합니다. 1~3차의 수정 내용은 변경 설명과 비교 이력에 남겼습니다.

추천서비스의 실제 사용자 기록이나 데이터셋 원본은 업로드하지 않습니다. 현재 최종 원문은 저자명·공식 소속·이메일·저자소개 사진과 연구 본문·도표를 보존하며 이전 공개본은 Git 변경 이력에서 확인할 수 있습니다.





#### LEVEL 3 · 원고가 보고한 결과와 한계

원고의 Ratings2는 24개 데이터셋·지표 조합 중 23개에서 향상을 보고하며, ML-1M MRR@10은 0.5603에서 0.5601로 감소합니다. Ratings5는 24개 모두 향상했다고 보고합니다.

CiaoDVD MRR@5는 0.0133→0.0155로 증가했으며 상대 향상률은 16.54%입니다.

CiaoDVD에서는 K=5의 세 지표 모두 Ratings5가 Ratings2보다 높지만, K=10에서는 Ratings2가 더 높습니다. 적합한 임계값은 데이터셋과 평가 K에 따라 달라집니다.

| 데이터셋 | 사용자 | 아이템 | 상호작용 수 | 평점 범위 |
| :--- | ---: | ---: | ---: | :--- |
| ML-100K | 943 | 1,682 | 100K | 1~5 |
| ML-Latest-Small | 610 | 9,724 | 100K | 0.5~5.0 |
| ML-1M | 6,040 | 3,706 | 1M | 1~5 |
| CiaoDVD | 17,615 | 16,121 | 72K | 1~5 |

위 규모는 원고 5쪽 표의 표기입니다. 원고는 ML-100K·ML-1M의 학습·시험 자료를 새로 분할했다고 설명하지만, 공개 실행 코드나 분할 목록은 제공하지 않습니다.

F1은 추천 목록의 정밀도·재현율을 함께, MRR은 정답의 순위를, NDCG는 순위에 따른 관련도를 비교하는 지표입니다. 결과는 모두 K=5·10으로 나누어 읽어 주세요.

실행시간·메모리 측정, 추가 그래프의 처리 비용과 통계적 유의성 검증은 후속 과제입니다. 그래프 가중치의 영향도 함께 평가할 필요가 있습니다.
