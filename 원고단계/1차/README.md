<a id="-이용-순서"></a>

## 이용 순서

1. 초록에서 전체 상호작용·평점 그래프의 두 경로를 파악합니다.
2. 방법의 그래프 필터와 가중 결합식을 읽고 표의 하이퍼파라미터를 확인합니다.
3. 네 데이터셋의 K5·10 결과를 지표별로 비교합니다.
4. 개선한 조합과 ML-1M MRR@10의 예외를 함께 읽고 결합 비율의 영향을 확인합니다.
